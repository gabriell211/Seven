# Seven Brand

Creator: Gabriel Barcelos

## Official Assets

- `seven-mark.svg`: square symbol for icons, app tiles and favicons.
- `seven-logo.svg`: horizontal logo for documentation, releases and repository header.
- `favicon.svg`: browser icon source.
- `seven.ico`: Windows icon generated from the official mark.

## Colors

- Night: `#0B1020`
- Panel: `#111827`
- Text: `#F8FAFC`
- Soft: `#94A3B8`
- Seven Green: `#22C55E`
- Seven Blue: `#38BDF8`

## Rules

- Do not distort the mark.
- Do not change the creator credit.
- Keep enough contrast around the mark.
- Use `seven-logo.svg` for repository and documentation headers.
- Use `seven-mark.svg` or `seven.ico` for executable/application icons.
