# Seven 0.2.1

Seven 0.2.1 e um patch de distribuicao para substituir o instalador Windows
0.2.0. O compilador auditado continua sendo a linha 0.2.0; a mudanca principal
e o empacotamento profissional e validado para instalacao no Windows.

## Destaques

- O Windows agora recebe um instalador MSI WiX profissional:
  `seven-0.2.1-windows-x64.msi`.
- O MSI instala por maquina em `%ProgramFiles%\Seven`.
- `bin\seven.exe` entra no PATH da maquina.
- Arquivos `.sev` sao associados ao Seven.
- O Seven aparece em Apps & Features e possui desinstalacao limpa.
- O Menu Iniciar recebe atalho oficial com o icone Seven.
- O MSI passa na validacao do Windows Installer antes de ser publicado.
- O payload Windows inclui `seven.webbuild.svbc` e `seven.webserve.svbc`.
- O pacote Linux tambem recebe os bytecodes Web no layout esperado pelo
  instalador nativo.
- A extensao VSCode foi versionada como `seven-language-0.2.1.vsix`.

## Por que esse patch existe

O pacote Windows 0.2.0 era um bundle de transicao. Ele colocava o compilador em
`payload/bin/seven.exe`, enquanto o instalador nativo antigo procurava
`payload/seven.exe`. O mesmo pacote tambem nao incluia os bytecodes
`seven.webbuild.svbc` e `seven.webserve.svbc` exigidos pela toolchain Web.

Na pratica, o instalador 0.2.0 podia falhar mesmo em uma maquina com Visual
Studio, .NET e ambiente correto. O 0.2.1 corrige isso promovendo o instalador
Windows para MSI e montando o payload de release de forma explicita.

## Artefatos

- `seven-0.2.1-windows-x64.msi`
- `seven-0.2.1-windows-x64.msi.sha256`
- `seven-0.2.1-linux-x64.tar.gz`
- `seven-0.2.1-linux-x64.tar.gz.sha256`
- `seven-language-0.2.1.vsix`
- `seven-language-0.2.1.vsix.sha256`

## Nota sobre VSIX

`seven-language-0.2.1.vsix` e uma extensao do Visual Studio Code. Ela deve ser
instalada pelo VS Code. O instalador principal da linguagem no Windows e o MSI.

## Limite honesto

Este patch nao declara self-hosting completo. A declaracao final continua
condicionada a prova deterministica entre `seven`, `seven.self` e os artefatos
oficiais.
