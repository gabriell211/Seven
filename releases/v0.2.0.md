# Seven 0.2.0

Seven 0.2.0 promove a linha de desenvolvimento Web e editor tooling sem
declarar self-hosting completo antes da prova deterministica final.

## Destaques

- `seven web build` gera pacote WebAssembly com `app.wasm`,
  `app.wasm.sha256`, `index.html`, `seven-loader.mjs` e `seven.web.json`.
- `seven web serve` entrega o pacote Web por servidor estatico de
  desenvolvimento validado no gate self-hosted.
- O backend Wasm emite controle estruturado para os padroes de `veja`, `gira`
  e `para cada`.
- O host Web gerado inclui objetos/listas por handle, iteradores, CSS/HTML
  tipados, temas, media queries e keyframes.
- `examples/frontend-counter` cobre UI interativa com DOM, evento,
  `localStorage` e conversao `Texto`/`Num`.
- `examples/frontend-rich` cobre CSS/HTML tipados, tema, media query,
  keyframes e iteradores.
- A extensao oficial VSCode `seven-language` registra `.sev`, adiciona
  gramatica TextMate e configuracao de editor pronta para VSIX.

## Artefatos esperados

- `seven-0.2.0-linux-x64.tar.gz`
- `seven-0.2.0-linux-x64.tar.gz.sha256`

- `seven-language-0.2.0.vsix.sha256`

## Limite honesto

React, Tailwind e APIs MDN reais continuam sendo ecossistemas JavaScript/Node.
O objetivo da Seven e oferecer equivalentes nativos da linguagem. Mapas ricos,
mais intrinsecos MDN, reatividade/estado de componentes e ergonomia de design
utilities ainda devem evoluir antes de declarar paridade frontend completa.

Self-hosting completo tambem permanece condicionado a prova deterministica
final entre `seven`, `seven.self` e os artefatos de release.
